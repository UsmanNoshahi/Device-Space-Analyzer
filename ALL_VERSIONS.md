## 🔧 Installation

### Install Python
1. Download from https://python.org
2. Version 3.6 or higher
3. Windows: Check "Add to PATH"

### Install Dependencies (Optional but Recommended)

**Windows (Automatic)**:
```bash
INSTALL.bat
```

**All Platforms (Manual)**:
```bash
pip install matplotlib squarify send2trash reportlab
```

**What Each Does**:
- `matplotlib`: Charts and graphs
- `squarify`: Treemap visualization
- `send2trash`: Safe file deletion (Recycle Bin)
- `reportlab`: PDF report generation

**Can run without dependencies?**
Yes! But some features disabled:
- No charts without matplotlib
- No treemap without squarify
- Permanent delete without send2trash
- No PDF without reportlab
