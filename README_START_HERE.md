## 🚨 Important Notes

### Safety
- ✅ **All deletions go to Recycle Bin** (can be recovered)
- ✅ **Confirmation required** before deleting
- ✅ **Read-only scanning** (never modifies files)
- ✅ **No internet access** (completely local)

### Performance
- Scans ~10,000 files/second on SSD
- Can handle millions of files
- UI stays responsive during scans
- Cancel anytime

### Requirements
- Python 3.6 or higher
- Windows, Mac, or Linux
- Optional libraries for full features
- ~150MB RAM for large scans
